# DevOps Roadmap

<!-- tl;dr starts -->

Being a DevOps Engineer, you need to know a lot of different skills and tech stacks.

<!-- tl;dr ends -->

## Tech Stack

1. Programming Language: **Python, Bash**
2. GNU/Linux distro: **Ubuntu, RHEL, FreeBSD (fast), OpenBSD (security), NetBSD (hardware compatibility)**
3. CLI tools: 
- Automation Scripting: **Python Click**
- Text editor: **vim, nano, emacs, ...**
- Network utility: **ifconfig, ip, iptables, ...**
- Process/Resource monitoring: **top/htop**
4. Version Control: **Git, GitHub/GitLab**
5. Cloud Providers: **AWS, Cloudflare, Azure, GCP**
6. Containerization: **Docker** (run, stats, swarm, volume, Dockerfile, docker-compose.yml, container registry, ...)
7. CI/CD: **GitHub/GitLab Actions, Jenkins**
8. Container Orchestration: **Amazon EKS, K8s, K3s**
9. Protocol: **DNS, SSL/TLS, SSH, HTTPS, ...**
10. Firewall, Web Server, Proxy (Forward/Reverse a.k.a Load Balancer), Certificates
11. Serverless: **Cloudflare Pages Functions, AWS Lambda, Azure Functions, ...**
12. Infrastructure Provisioning: **Terraform, AWS CloudFormation**
13. Configuration Management: **Ansible, Chef, ...**
14. Infrastructure Monitoring: system logs, resource metrics, data streams **Datadog, Grafana, Prometheus, Zabbix, ...**
15. Application Monitoring: error could happen when migration happens (DB schema, update verions, ...) **Datadog, ...**
16. Misc:

- **Log:** ELK (Elasticsearch, Logstash, Kibana)
- **Artifactory** 
- **Nexus**: a self-hosted Repository Manager.
- **Service Mesh**: helps services located in different providers (e.g. **AWS EC2** and **Azure VM**) can talk to each other.
- **Cloud Design Pattern**.

## Job titles

- Site Reliability Engineer (SRE)
- Cloud Engineer
- System Engineer
