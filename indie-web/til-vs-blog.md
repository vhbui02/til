# TIL Vs Blog

Here are some key differences between two aspects:

| Aspect      | Today I Learned (TIL)                                          | Blog                                                                       |
| ----------- | -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Length      | Very short (1-3 sentences)                                     | Long (multiple paragraph)                                                  |
| Frequency   | Daily, as-you-learn                                            | Weekly, monthly                                                            |
| Formality   | Informal, quick note                                           | Structured                                                                 |
| Audience    | Yourself first                                                 | Broader                                                                    |
| Time/Effort | Less                                                           | More                                                                       |
| Pros        | Easy recall by owner                                           | Edge-case tips discovery                                                   |
| Cons        | Little downside                                                | Fragmented, not recommended for newcomers, requires more context switching |
| Purpose     | Small learnings (a sentence, a paragraph, a code snippet, ...) | In-depth explanations, full tutorials, best practices, ...                 |

## Make TILs more visitor friendly

- Tagging and categorization
- Linking related TILs.
- Writing roundup blog posts (weekly/monthly) summarizing related TILs (e.g. 5 Git Tips I learned this month)
- Adding search features.
