## Popular built-in exception classes

```
AssertionError: raise when an assert statement fails.
ValueError: value has correct type but incorrect value.
TypeError: value has incorrect type.
RuntimeError: more specific that Exception only a little.
Exception: general error that can be thrown in any situations.
```
