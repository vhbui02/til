# DNS Records

## Mail Exchange (MX)

DNS MX record directs emails to a mail server, in accordance with the Simple Mail Transfer Protocol (SMTP).

| `<domain>` | Type | Priority | Value            | TTL   |
| ---------- | ---- | -------- | ---------------- | ----- |
| @          | MX   | 10       | mail.example.com | 45000 |
| @          | MX   | 20       | smtp.example.com | 45000 |

```
Sender MUA
  |
  HTTP/SMTP
  v
Sender MTA  <-- DNS MX record --> Cache/Root/TLD/Authoritative Server: example.com
  |
  SMTP
  v
Recipient MTA ...
```

MTA is reponsible for querying MX records.

## DomainKeys Identified Mail (DKIM)

It's an email authentication method to **prevent malicious actors from impersonating a legitimate domain**.

### Logic

There are 2 main aspects of `DKIM`:

- `DNS DKIM record`: store inside authoritative nameserver.
- `DKIM header`: attached to add emails from the domain. Can be called the email's digital signature.

The email provider generates the public key and private key. The public key is stored inside `DNS DKIM record`.

Emails sent from the authentic email provider include a `DKIM header`, which contains a section of data calculated from email headers + email body then signed by the private key.

Email server fetched the `DKIM DNS record`, obtain the public key then use it to verify the `DKIM header`.

=> Any attempt to craft a fake `DKIM header` or tampar with an authentic `DKIM header` is impossible.

=> However, it's very dangerous if the authoritative nameserver, where the sensitive `DNS DKIM record` is stored, get compromised.

### DNS DKIM record structure

DNS DKIM record is an implementation of DNS TXT record:

| Name                             | Type  | Content               | TTL  |
| -------------------------------- | ----- | --------------------- | ---- |
| `<selector>._domainkey.[domain]` | `TXT` | `v=DKIM1; p=<pubkey>` | 3600 |

1. `<selector>`:

- special value issued by email service provider used by the `.[domain]`
- included in email's DKIM header.
- `[domain]` is the email domain name `@[domain]`
- E.g. `big-email._domainkey.example.com` if email service provider is Big Email.

2. Content:

- `v=DKIM1;` => TXT records should be interpreted as DKIM
- `p=<pubkey>` => the public key, generated by email service provider.
